## 候选路线与边界

小 CNN 编码当前 RGB-D（另含有效深度 mask），与测量地图特征、任务反馈、
sin/cos 关节位置、实测速度、上次实际执行增量融合，经 128 维 GRU 得到
16 维动作分布参数和三类 none/capture/release 请求。当前仅实现网络接口，
尚未接入 PPO 分布/训练器，不能把网络 forward 测试说成训练。

关节目标按实测状态递推，不能累加被拒绝动作。传统几何过滤保留自碰撞、
两臂互碰撞、宇航员结构、RGB-D 环境与载荷检查。惩罚不能代替硬约束。
若机器人正在运动，拒绝动作应触发已有认证制动，不能瞬间设置零速度。
PPO 保存原始策略动作及其 log-prob，另外记录过滤后/实际动作，不能用执行动作
冒充原始策略采样。actor/critic 均不读取环境真值、真实物体数量或未来帧。

## 训练阶段（尚待环境接入）

1. 实际 IsaacLab 相机与机器人运动/坐标检查，1/4/16 环境吞吐和显存测试。
2. 接近、磁吸、抬升、放置、撤离技能及安全过滤集成，覆盖原失败例。
3. 新初始化小网络；可用同一训练种子集的有效轨迹进行模仿预热。
4. recurrent PPO，逐渐增加物件数、尺寸/角度/高度变化与遮挡。最终不只测简单课程。
5. 验证集选择冻结模型；独立 1000 场完整随机测试至少 990 成功，并报告置信区间。

拟定奖励：稀疏整场完成为主要正奖励，阶段成功仅计一次；基于测量的任务进度
与地图新证据采用有界 shaping，重复观察同一证据不给额外信息收益；视觉质量
仅在推进任务/恢复必需观测时提供 shaping，不能原地看着目标刷分。
时间成本、动作抖动、安全过滤介入、实际失败/碰撞负奖励；反作用奖励为零。
数值权重与 gamma 必须在环境步长/有效回合预算确定后冻结。
终止/截断需分开，碰撞和真实失败终止；超时计任务失败但 PPO bootstrap 按接口处理。

## 随机化与验收

`protocol.json` 分离训练、验证、正式测试种子；最终拟覆盖 1–6 物体、四类基本体
和螺栓/螺母/扳手/螺丝刀，台高 0.70–0.82 m、yaw 全范围、倾斜 ±30°。
这些是有界任务域，不是任意不可达位置或任意三维姿态；尺寸/摆放/支撑条件与
采集预算尚需在正式试验前固化，不能筛选失败场景。现有磁吸接口任务先验保留，
不宣称支持任意裸工具语义识别。旧三色三槽位不能直接代表六物体环境，必须改造。
初始地图只能来自有原始记录的 RGB-D；不同扫描预算必须明确报告。
测量算法未发现的物体也会导致独立整场审计失败，不能把队列为空等同于成功。
99% 为点估计门槛；不能把 990/1000 说成总体成功概率至少 99% 的统计证明。
