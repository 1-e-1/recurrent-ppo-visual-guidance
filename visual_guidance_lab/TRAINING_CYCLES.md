# 随机场景直接训练（2026-09-16）

当前入口：`python -m visual_guidance_lab.train_cycles --output reports/<新目录>`。
这是“随机场景 → 在线 PPO → 冻结验证 → 继续训练”的自动循环，
不是已经达到 99%，也不是 IsaacLab 多环境任务并行。
旧 `run_pilot` 的 IK 前置残差方案保留用于对比，不再作为本轮动作接口。

## 本轮配置

- `reports/visual_guidance_direct_cycles_01`：新随机权重，2 个循环，每个循环训练 2 场、冻结验证 1 场。
- 每场首个接近阶段最多 64 步；后续抓放阶段沿用原有限步状态机，因此 64 不是整场总步数。
- 首轮课程物体数 1–2，8 种外形均可能出现，尺寸/位置/水平角/台面高度随机；倾斜角暂为 0。
- 生成器支持 1–6 个物体和 ±30° 倾斜，尚不能据此宣称控制器已能完成倾斜接口抓放。
- 初始关节在原始可用姿态附近均匀扰动 ±0.12 rad，最多 64 次安全采样。
  这不是全关节范围均匀采样，也不是从零位运动过去。仅检查机器人和 RGB-D 环境安全，
  不按任务成功或可见性筛选。采样失败整场计失败，不换 seed。
- 每场随机环境重新采集 786 帧模拟部署前 RGB-D，保留原始记录和 hash。
  这是用户允许的初始地图条件；不是自主腕部预扫描，更不是读取真实场景几何给控制器。

## 网络和学习

RGB-D 五通道 CNN + 关节 sin/cos、速度和实际执行增量 + 64 维观测空间历史特征
+ 24 维视觉任务特征 → 128 维 GRU → 16 维关节动作分布及 value。
从零初始化约 17.8 万参数。动作 `q_next = clip(q_measured + 0.02*tanh(u))`。
策略先于 IK 产生动作，不要求传统 IK 先成功。磁吸开闭、阶段切换和缺失视角恢复暂沿用传统模块。

环境/机器人连续安全检查决定动作是否执行；被拒绝的动作不进入关节累加器，
若当前位置仍获安全证书则保持静止一段控制时间，否则终止/恢复，不盲目移动。
仍要求任务视觉约束，因此当前不能自由离开任务视野进行全局扫描。

奖励：截断的视觉目标距离进度 + 0.2×朝向改善 + 0.05×有界新观测表面格增益
+ 10×已观测对象完成数 − 0.3×拒绝动作 − 0.01步代价 − 2×终止失败。
朝向在没有指定目标轴时暂以采样前方向为参考，不等于任意姿态任务学习。
地图新格奖励是粗粒度信息增益，不是精度或碰撞安全证书。
反作用奖励为 0；执行仍有原有关节速度/加速度/jerk 限制。

PPO 每 16 样本或回合末更新，4 epochs，Adam 1e-4，gamma=.99，lambda=.95，
clip=.2，value=.5，entropy=.001，梯度裁剪 .5，初始 Normal log_std=-.7。
保存原始动作及 log probability；不用被过滤后的动作替换策略采样。
到期未完成算任务失败，当前有限时域奖励实现按 terminal 处理。

## 验证与记录

训练 seed 从 100000 开始，验证 seed 从 900000 开始，彼此分离。
验证使用冻结权重和确定性动作，不执行 optimizer 更新。
完整成功要求独立场景对象/抓放/几何审计、时钟审计和源代码未变；
队列空、程序正常退出、部分物体完成、奖励上涨都不是整场成功。
训练过程的成功率与冻结验证成功率分别报告；本批不是正式 1000 场验收。

`progress.json`：当前阶段与累计结果；每场 `mission/learning_progress.json`：
实际样本和本场新增更新；`episode.json`：包括初始化失败、进程超时在内的结果。
训练权重连续传递，验证输出不替换训练权重；输入权重 hash 校验防止验证污染。
每批保存源码 ZIP 和 hash。磁盘余量不足 20 GiB 时暂停，不删除原始证据。

当前效率限制是逐场初始扫描、几何证书和串行传感器，而不是小网络前向。
IsaacLab 4 相机 smoke test 已通过，但没有完成独立任务克隆/向量化，
不能把已有相机阵列称为并行强化学习训练。
